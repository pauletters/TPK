## Description
A web browser based, MERN Stack, Tabletop RPG Character Companion App, allowing users to create and manage their RPG characters, and manage campaigns with friends.

## Installation
No installation necessary, navigate to the application [HERE](https://total-player-knowledge.onrender.com/)

## Usage

### Authentication
- Navigate to the app's web page and locate the Login/Signup Button in the top right corner
- Click the button to open the authentication modal
- For new users, select the Signup tab to create an account
- For existing users, enter your credentials to log in

### Character Management


#### Viewing and Creating Characters
![My Characters](/public/assets/screenshots/My-Characters.png)
From the My Character page, you can:
- View existing characters by clicking the "View" button on any character card
- Create new characters by clicking the "Create New Character" button
#### Character Creation Process
![Character Creation](/public/assets/screenshots/Character-Creation.png)
After initiating character creation:
- Fill out the form modal with:
  - Basic Information
  - Attributes
  - Combat values
  - Skills values
- Browse through available avatars using the carousel buttons
- Click "Save Character" to complete creation or "Cancel" to discard

#### Character Details
The Character Details page contains multiple tabs:

##### Details Tab
![Character Details](/public/assets/screenshots/Character-Details.png)
![Character Editing](/public/assets/screenshots/Character-Editing.png)
- View all character information
- Click "Edit" to modify character values
- Save changes using "Submit Changes"

##### Spells Tab
![Spells](/public/assets/screenshots/Spells.png)
- Add spells by clicking "Add Spell"
- Filter spells by class and search functionality
- Click spells to add them to your character
- View full spell details via "Full Details" button
- Toggle spell preparation status
- Remove spells using the red X button

##### Equipment Tab
![Equipment](/public/assets/screenshots/Equipment.png)
- Add equipment similar to spells
- No class restrictions on equipment selection
- Remove items as needed

##### Background Tab
![Background](/public/assets/screenshots/Background.png)
- View background details
- Manage custom backstory:
  - Add new backstory
  - Edit existing backstory
  - Remove backstory

##### Class Features Tab
![Class Features](/public/assets/screenshots/Class-Features.png)
- View class feature details by clicking expand arrows

### Campaign Management

#### Campaign Overview
![My Campaign](/public/assets/screenshots/My-Campaigns.png)
Access the My Campaigns page to:
- View all campaigns your characters are enrolled in
- Create new campaigns

#### Creating a Campaign
![Campaign](/public/assets/screenshots/Campaign-Creation.png)
1. Click "Start Now" to initiate campaign creation
2. Enter required information:
   - Campaign name
   - Campaign description
   - Add characters by searching for users
3. Click "Create Campaign" to save or "Cancel" to abandon

#### Campaign Dashboard Features
![Campaign Dashboard](/public/assets/screenshots/Campaign-Dashboard.png)
- View character cards for all campaign members
- Access public character details by clicking their cards
- Private characters will have restricted access
- Add campaign milestones:
  - Type milestone in the input field
  - Click "Add Milestone"

#### Campaign Management (Creator Only)
![Campaign Editing](/public/assets/screenshots/Campaign-Editing.png)
Campaign creators can:
- Edit campaign name and description
- Manage characters:
  - Add new characters via "Add Player"
  - Remove existing characters via "Remove Character"

### Dice Roller
![Dice Roller](/public/assets/screenshots/Dice-Roller.png)
- Click the Dice Roller tab to expand
- Select number and type of dice
- Click "Roll" to roll dice
- View roll history below dice tray
- Clear history using "Clear History" button
